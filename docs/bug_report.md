# Bug report

## Current status

No confirmed design bug has been recorded yet. The supplied expected-value checks and assertion monitors are intended to expose mismatches during the simulation run. This report is deliberately not populated with invented failures.

## Record a discovered issue

For each real failure, add:

- Bug ID and date
- Design/testbench revision
- Reproduction command and stimulus
- Expected behavior and actual behavior
- Root cause
- Fix and affected files
- Regression test and final simulation result

Until a failing simulation is observed, keep the status as **No confirmed bug observed** rather than claiming that bugs were found and fixed.
